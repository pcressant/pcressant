# Hi, I'm Patrick

I build accessible Linux desktop tools that work well with screen readers.

## Projects

**[ScanOCR](https://github.com/pcressant/scan-ocr)** — an accessible GTK4 application
that scans a page through SANE, recognizes its text with Tesseract, and lets you
read and correct it with Orca.
[Latest release](https://github.com/pcressant/scan-ocr/releases/latest)

**[NVDA RDP Linux](https://github.com/pcressant/nvda-rdp-linux)** *(experimental)* —
lets a blind Linux user work in a Windows remote desktop with the remote NVDA
screen reader, hearing its speech and reading its braille locally through
Speech Dispatcher and BRLTTY. The Linux counterpart of the RDAccess client.
